``` r
mean(pull(problem_df, num_var), na.rm = TRUE)

mean(pull(problem_df, fact_var), na.rm = TRUE)

as.numeric(mean(pull(problem_df, log_var), na.rm = TRUE))
as.numeric(mean(pull(problem_df, char_var), na.rm = TRUE))
as.numeric(mean(pull(problem_df, fact_var), na.rm = TRUE))
```

Taking the mean of a numeric vector or a logical vector work but not
taking the mean of a character vector or a factor vector. Even after
using the function `as.numeric` only logical and numeric vectors work.
You would get warning that says argument is not numeric or logical:
returning NA (not applicable).
